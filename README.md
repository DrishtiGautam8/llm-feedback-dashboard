# LLM-Feedback-Dashboard

# 🩺 Medical Chatbot – LLM Feedback Evaluation Dashboard

Welcome to the **LLM Feedback Dashboard**, built to evaluate responses from a **Medical Chatbot** powered by large language models (LLMs).  
This project is part of a broader **automated pipeline** I built to collect real-world queries, generate LLM responses, and now—gather structured human feedback.

---

## 🚀 Try the Feedback App

👉 [Click here to open the LLM Feedback Dashboard](https://llm-feedback-dashboard-a5zctwbd2qtfnruicc3nvv.streamlit.app/)

## 🧩 What You’ll See

- A real **user query** from the medical chatbot dataset.
- **Multiple LLM responses** shown side-by-side.
- Rubrics to evaluate each response on:
  - ✅ **Accuracy**
  - ✅ **Helpfulness**
  - ✅ **Readability**
- A dropdown to **select the best model** overall.

---

## ✅ How to Use

1. **Read the query and model responses carefully.**
2. **Rate each model** on all three rubrics using the radio buttons.
3. **Select the best model** based on your judgment.
4. Click **✅ Submit Feedback** to store your response.

## ⚠️ Important Notes

- ⏳ **Do not refresh the page** while the **“Running” indicator** (top-right) is visible.
  ![running-widget](https://github.com/user-attachments/assets/760c0231-acd4-4c39-89b8-9fa7bd583e8a)
  
- 🔁 **To provide feedback again**, reload the page after a successful submission.
  ![How-to-reload](https://github.com/user-attachments/assets/0482f48d-ad62-4938-b942-a7094e11d52c)
  
- ❌ **If you encounter a submission error**, make sure:
  - All **rubrics are filled** for each model.
  - You’ve selected a **best model** from the dropdown.
  - Then, click **Submit** again.
  ![error-widget](https://github.com/user-attachments/assets/889d2493-b37e-4ea5-9055-f2bdb1698d1a)

## 💡 Behind the Scenes

This dashboard is part of a custom **automation pipeline** that:
- ✅ Collected real medical queries from chatbot usage.
- ✅ Generated responses from multiple LLMs.
- ✅ Displays them here for structured evaluation.
- ✅ Stores results directly into a connected **Google Sheet** for analysis.
